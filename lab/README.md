# Ampersand Audio Lab

This boundary is for rights-cleared fixtures, reproducible experiments, listening tests, and quality reports. Production customer media must never enter it. Research-only components cannot be referenced by production recipes without an approved admission manifest.

Implemented foundations:

- deterministic synthetic control corpus and immutable lineage manifests;
- local-only blinded preference/clean-preservation harness;
- loudness, peak, clipping, full-reference, runtime, memory, device, and cost diagnostics;
- versioned delayed-reveal score and report contracts.

Generated corpus audio, listening copies, scores, and private reports remain outside Git.
